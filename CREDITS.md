# Credits and relationship to Laragon

XLaragon is an independent Windows companion application intended to work alongside an existing Laragon installation. It does not replace Laragon and does not include Laragon or the services installed in the user's Laragon folder.

XLaragon reads and updates settings and configuration files in the Laragon installation selected by the user. Laragon and its name are the property of their respective owners. XLaragon is not affiliated with or endorsed by the Laragon project.

## Runtime

The application is built with .NET and Windows Forms. It does not bundle web servers, databases, PHP, or other third-party services.
